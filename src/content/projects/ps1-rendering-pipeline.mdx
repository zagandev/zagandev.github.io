Been experimenting with Unity and learning about the Scriptable Render Pipeline (SRP) to make a custom one and start diving deep into the graphics pipeline while trying to mimic a retro-style rendering.

The idea was to have a minimum renderer capable of supporting directional, point/spot lights, as well as real-time shadows. And the scene is rendered at 320x240 using the ARGB16 format; when ready, it's presented at 1280x960, and it uses the ARGB32 format.

To add extra details, I implement a bloom effect, dithering, distance fog, and a CRT adapted for HLSL.
